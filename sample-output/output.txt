========================================================================================
                        COMPARE SINGLY vs DOUBLY LINKED LIST
========================================================================================
Property                 | Singly Linked List            | Doubly Linked List
-------------------------+-------------------------------+------------------------------
Pointers per Node        | 1 (next)                      | 2 (prev and next)
Memory Consumption       | Lower memory overhead         | Higher memory overhead
Traversal Direction      | Forward only                  | Bidirectional (forward & back)
Insert at Beginning      | O(1)                          | O(1)
Insert at End            | O(n) without tail             | O(1) with tail / O(n) without
Delete from End          | O(n) (requires traversal)     | O(1) with tail reference
Delete Given Node Ref    | O(n) (need previous node)     | O(1) (direct relink via prev)
Reverse Operation        | Requires pointer reversal     | Reverse pointers or read tail
Implementation Overhead  | Simpler pointer logic         | More complex (two-way links)
Ideal Use Cases          | Stacks, Simple queues, RAM    | Navigation, History, Playlists
========================================================================================

Summary:
Choose Singly Linked List when memory conservation is critical and forward traversal suffices.
Choose Doubly Linked List when backward navigation and frequent arbitrary deletions are required.
